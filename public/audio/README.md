# Carpetas de Canciones MP3 por Categoría

Coloca tus archivos MP3 / WAV directamente en estas carpetas según corresponda:

- `public/audio/presentation/` -> Canciones para Calentamiento y Presentación Oficiales.
- `public/audio/point_intros/` -> Intros de 12 segundos para Entrepuntos (La Chona, El Meneadito, etc.).
- `public/audio/technical_timeouts/` -> Música de 1 minuto para Tiempos Técnicos y Fuera (La Macarena, etc.).
- `public/audio/super_spike/` -> Efectos o canciones de impacto para Super Spike.
- `public/audio/monster_block/` -> Efectos o canciones de impacto para Monster Block.

La aplicación detectará y reproducirá directamente los archivos de estas carpetas.
